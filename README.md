# 🧪 ML Laboratory

This repository is my personal **Machine Learning Laboratory**.

The goal is not simply to use libraries such as `scikit-learn` and call `.fit()`.

Instead, I want to understand **how and why Machine Learning algorithms work**, implement their core ideas myself, experiment with them, visualize their behavior, and finally apply them to real-world problems.

# 🚀 Final Goal

The ultimate goal is not to memorize every algorithm.

The goal is to reach a point where, given a new ML problem, I can answer:

> **What is the structure of this problem, what assumptions can I make, what representation should I use, which algorithm fits those assumptions, how should I train it, and how do I know whether it actually works?**

This repository is the journey toward that understanding.

---

## 📌 Philosophy

> **Don't just use the algorithm. Understand the algorithm.**

> **Don't just train the model. Understand why it learns.**

> **Don't just look at the accuracy. Understand the data, assumptions, errors, and limitations.**
